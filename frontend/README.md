## 📖 What is OnBoard?

Big social networks have turned into digital billboards—endless algorithmic feeds, sponsored influencer clutter, and stressful follower counts.

**OnBoard flips the script.** Built from the ground up as a **"digital living room"**, OnBoard provides an intimate space where:

- You only see posts from people who have mutually boarded you into their **Crew**.
- You celebrate your daily vibe using an interactive **VIP Boarding Pass** profile.
- You can discover creators authentically on your own terms in the **Horizon Lounge** without being tracked by predatory ad algorithms.

## ⚡ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- MongoDB URI (Atlas or local instance)
- ImageKit account (for free image upload keys)

### 1. Clone the Repository

```bash
git clone https://github.com/imdigvijaysingh/OnBoard-social_media-app.git
cd OnBoard-social_media-app
```

### 2. Configure the Backend

Navigate to the `Backend` directory and install dependencies:

```bash
cd Backend
npm install
```

Create a `.env` file in `Backend/` with your credentials:

```env
PORT=3000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_super_secret_jwt_key
IMAGEKIT_PUBLIC_KEY=your_imagekit_public_key
IMAGEKIT_PRIVATE_KEY=your_imagekit_private_key
IMAGEKIT_URL_ENDPOINT=your_imagekit_url_endpoint
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_email_app_password
```

Start the backend server:

```bash
npm run dev # or node server.js
```

### 3. Configure the Frontend

In a new terminal window, navigate to `frontend`:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application!
